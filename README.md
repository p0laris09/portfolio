# Anne Lorraine Ramos - Portfolio

A beautifully crafted personal portfolio website showcasing my projects, experience, and skills in web and mobile development.

## About

Welcome to my portfolio! I'm a passionate full-stack developer dedicated to creating clean, intuitive digital experiences. This portfolio features my latest projects, technical expertise, and professional journey.

## Features

- **Responsive Design** - Fully responsive across all devices
- **Dark Forest Theme** - Elegant dark theme with green and golden accents
- **Project Showcase** - Interactive project timeline with image galleries
- **Smooth Animations** - GPU-optimized animations and transitions
- **Image Galleries** - Full-featured image galleries for mobile app projects
- **Keyboard Navigation** - Accessible keyboard controls throughout

## Sections

- **Home** - Hero section with professional introduction
- **About** - Background and skills overview
- **Experience** - Professional experience timeline
- **Projects** - 10+ featured projects with galleries
- **Certificates** - Professional certifications and achievements
- **Contact** - Get in touch
